\begin{englishabstract}

With the rapid progress of Large Language Models (LLMs), natural-language Shell assistants are lowering the barrier to command-line usage. However, most existing systems rely on cloud APIs and remain weak in Chinese operations scenarios: colloquial intent understanding is unstable, domain knowledge coverage is limited, and high-risk commands are hard to constrain before execution; privacy and network dependency further hinder stable local deployment.

This thesis proposes an LLM-based Shell agent that combines local RAG with a safety-oriented execution pipeline. The system uses a client-server architecture: the server runs a 4-bit quantized Qwen-7B model, while the client handles session orchestration, stepwise execution, and user confirmation. A three-layer SQLite memory design (short-term, long-term, and summary) preserves multi-turn context. We build a Chinese Shell knowledge base with 45 documents and 88 text chunks, apply hybrid retrieval with weighted reranking (dense vectors + keyword signals), and implement a guarded pre-execution chain of syntax validation, risk grading, effect simulation, and structured auditing.

Results show strong engineering feasibility. On an 80-query natural-language benchmark, the best configuration reaches SrcHit = 0.975, MRR = 0.9375, nDCG = 0.9105, and Recall@1 = 0.900, improving Recall@1 by 4.3 percentage points over the pure vector baseline. In end-to-end evaluation on 50 representative queries, the system achieves 92.0\% syntax accuracy, 78.0\% high-or-medium semantic match rate, and 54.0\% sandbox dry-run success rate, while proactively blocking 40.0\% high-risk outputs. These findings confirm a retrievable, interpretable, and controllable local assistant for common Chinese Shell operations.

\end{englishabstract}
