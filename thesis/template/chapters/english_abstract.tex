\begin{englishabstract}

Large Language Models (LLMs) enable natural-language interfaces for command-line tools, but Chinese Shell assistance still requires a practical balance among retrieval quality, command correctness, and execution safety. This thesis presents an LLM-based Shell agent that integrates Retrieval-Augmented Generation (RAG) with a guarded execution pipeline in a local deployment setting.

The system adopts a client-server architecture. The server hosts a locally quantized Qwen-7B model, while the client handles session orchestration, user confirmation, and stepwise execution. A three-layer memory design (short-term, long-term, and summary memory) is implemented with SQLite to preserve multi-turn context across sessions.

For knowledge grounding, we build a Chinese Shell knowledge base with 45 documents and 88 text chunks, and propose a hybrid retrieval strategy that combines dense vector similarity with keyword-aware weighted reranking. On an 80-query natural-language benchmark, the best configuration achieves SrcHit = 0.975, MRR = 0.9375, nDCG = 0.9105, and Recall@1 = 0.900, outperforming the pure vector baseline on major ranking metrics.

For safety-aware generation, we design a pre-execution chain of syntax validation, risk grading, and effect simulation, together with permission checks and structured audit logging. In end-to-end generation evaluation on 50 representative queries, the system obtains 92.0\% syntax accuracy, 78.0\% high-or-medium semantic match rate, and 54.0\% sandbox dry-run success rate, while proactively blocking 40.0\% high-risk outputs.

Results indicate that the proposed approach is engineering-ready for common Chinese Shell operation scenarios, providing a controllable and auditable path from natural-language intent to executable commands.

\end{englishabstract}
